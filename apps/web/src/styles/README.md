# Styles

Purpose: shared tokens and page-level styling for the frontend.

Ownership: Frontend.

## What Lives Here

- `tokens.css`: shared design tokens.
- `base.css` and `index.css`: baseline app styling.
- `marketing.css`, `planner.css`, `auth.css`, `responsive.css`: route and layout styling.

## Notes

- Keep global tokens centralized and prefer building page styles on top of them.
- If visual language changes materially, update the corresponding frontend docs.
